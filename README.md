# steute Technologies GmbH & Co. KG

steute Technologies GmbH & Co. KG is a German industrial technology company (Löhne, "Applied Intelligence") building switchgear, sensors and controls across three divisions: Meditec (certified user interfaces for medical devices), Controltec (safe industrial automation) and Leantec (digital shop floor solutions). Its Leantec "nexy" IIoT wireless network (sWave.NET radio, AES-128) connects wireless switches and sensors to shop-floor IT via an on-premise Sensor Bridge gateway.

The Sensor Bridge exposes a JWT-secured REST API (OpenAPI 3.0.0, 27 operations — harvested in `openapi/`), HTTP(S) push notifications (captured as AsyncAPI in `asyncapi/`), Modbus TCP and optional OPC UA / SAP modules. System documentation lives at [docs.nexy.net](https://docs.nexy.net/).
