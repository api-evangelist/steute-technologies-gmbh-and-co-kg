# steute Technologies GmbH & Co. KG

> German industrial technology company (Löhne, "Applied Intelligence") building switchgear, sensors and controls across three divisions: Meditec (certified user interfaces for medical devices), Controltec (safe industrial automation) and Leantec (digital shop floor solutions). The Leantec "nexy" IIoT wireless network (sWave.NET radio, AES-128) connects wireless switches and sensors to shop-floor IT via a Sensor Bridge gateway exposing a JWT-secured REST API, HTTP(S) push notifications, Modbus TCP and optional OPC UA / SAP modules.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-07-21. No provider-published llms.txt exists (404 on steute.com and docs.nexy.net).

## APIs

- [nexy Sensor Bridge REST API v2](https://docs.nexy.net/docs/sensor-bridge/rest-api/): On-premise OpenAPI 3.0.0 API (27 operations) for switches, switch groups, access points, event history, notification configs and system status. JWT auth via /api/v2/auth/login (JWTAuthorization header, 30-min tokens). Swagger UI at /api-demo-v2/ on the device.
- [HTTP(S) Notifications](https://docs.nexy.net/docs/api-and-protocols/https-notifications/): JSON webhook push (switchEvent, missingSwitchWakeupWarning) with HTTP Basic auth, group filtering and wake-up monitoring.
